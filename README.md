# Subhamaity Associates | Financial & Tax Consulting Platform

A modern, high-performance, and SEO-optimized web application built for **Subhamaity Associates**—a premier tax consulting and financial service provider in West Bengal, India.

Built with **Next.js (App Router)** and styled with **Tailwind CSS**, this platform delivers a seamless, blazingly fast user experience designed for lead generation and business compliance.

---

## 🚀 Key Features

- **Interactive Mega-Menu Navigation:** A clean desktop mega-menu categorizing all professional services for instant user access.
- **Instant GST Calculator:** A built-in calculator tool allowing clients to quickly compute net, gross, and GST amounts on the fly.
- **Dynamic Service Pages:** Dedicated pages for each financial service complete with overviews, service types, required documents, common mistakes to avoid, and structured FAQ sections.
- **Advanced SEO Integration:** Fully equipped with automated `sitemap.xml`, `robots.txt`, and injected **JSON-LD FAQ Schema** for high Google search ranking.
- **Swiggy/Zomato-Style Location Map:** Modern interactive office map embedding featuring a frosted-glass overlay card with direct navigation links.
- **Global WhatsApp Floating Action Button (FAB):** Persistent contact point following users across all pages, driving direct client conversions.
- **Secure Contact Form:** Integrated with Web3Forms for reliable client inquiry handling.
- **Smooth Page Transitions:** Buttery-smooth fade and slide animations between pages using Next.js templates.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Static Export ready)
- **Library:** [React](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Language:** TypeScript / JavaScript
- **Form Backend:** Web3Forms
